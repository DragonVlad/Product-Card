# Product Card

Учебный проект интерактивной карточки товара, созданный для демонстрации навыков современной адаптивной верстки, работы с анимациями и манипуляций с DOM.

## 📈 Демонстрация прогресса (Эволюция проекта)

Главная цель этого репозитория — показать переход от базовой верстки к продвинутой оптимизированной разработке с использованием современных инструментов.

* **Ветка `main` (Текущая):** Базовая рабочая версия. Проект построен на стандартных HTML-тегах (`div`, `h2`, `p`), кастомном CSS3 с использованием Flexbox-сетки и ванильном JavaScript. Реализован адаптивный дизайн под мобильные устройства и интерактивная система рейтинга.
* **Ветка `feature/modern-vite-scss`: ** Профессиональная версия сборки. Проект полностью переработан и оптимизирован для удобной разработки. Архитектура стилей переведена на препроцессор **SCSS** с активным использованием **вложенных селекторов** (nesting) для чистой структуры и **SCSS-переменных** ($variables) для удобного управления цветами и отступами. Разметка и стили полностью переписаны по методологии **БЭМ** для независимости компонентов, а весь проект упакован и запускается через современный быстрый сборщик **ViteJS**.

### Реализованный функционал (Ветка `main`)
* **⭐ Интерактивный рейтинг:** Скрипт на JS отслеживает события мыши (`mouseover/mouseleave`), динамически подсвечивает звезды классами и заменяет контурные символы `☆` на закрашенные `★`.
* **✨ Микро-взаимодействия:** Реализован hover-эффект приподнимания и увеличения изображения (`transform: scale / translateY`) с добавлением плавных переходов `transition`.
* **📱 Мобильный адаптив:** С помощью медиа-запроса `@media (max-width: 500px)` карточка перестраивается под экраны смартфонов, уменьшая пропорции обертки и элементов.

### Реализованный функционал (Ветка `feature/modern-vite-scss`)
* **🚀 Оптимизация производительности:** Благодаря сборщику ViteJS, все ресурсы (SCSS-стили и JS-скрипты) автоматически минифицируются при сборке, уменьшая вес страницы и ускоряя её загрузку.
* **📐 «Резиновая» адаптивность (Fluid Layout):** Элементы карточки плавно масштабируются в зависимости от ширины экрана без резких скачков (благодаря переходу на проценты `%` вместо пикселей `px`). Карточка идеально подстраивается под нестандартные разрешения экранов.
* **🎨 Масштабируемая дизайн-система:** Вынос ключевых параметров (цветовая палитра интерфейса, отступы) в SCSS-переменные позволяет изменить тему оформления всего проекта (например, сделать её темной или сменить акцентный цвет) буквально в одну строчку кода.
* **🧩 Модульность и изоляция стилей:** Архитектура БЭМ гарантирует, что стили карточки товара независимы от глобального окружения. Компонент можно безопасно перенести на любую другую страницу или сайт, не боясь, что верстка «поедет» или сломает другие элементы.

## 🛠 Технологический стек

### Базовая версия (`main`):
* HTML (Блочная разметка структуры)
* CSS3 (Flexbox-позиционирование, анимации перехода `transition`, `@media` запросы)
* Vanilla JavaScript (Работа с DOM, обработка событий мыши, циклы `forEach`)

### Прокачанная версия (`feature/modern-vite-scss`):
* **Окружение и сборка:** ViteJS (Локальный dev-сервер, автоматическая минификация ресурсов, Hot Module Replacement)
* **Архитектура стилей:** 
  * Препроцессор **SCSS** (Вложенные селекторы для чистоты каскада, кастомные переменные ($variables) для темизации)
  * Методология **БЭМ** (Изолированное и независимое именование классов компонентов)
* **Адаптивность:** Fluid Layout (Перевод интерфейса на гибкие процентные соотношения `%`)
* **Интеграция:** Импорт главного SCSS-файла стилей напрямую в JavaScript для обработки сборщиком Vite.
* **Логика:** Оптимизированный Vanilla JS (Разделение кода на функции с четкими зонами ответственности).

## 🚀 Как запустить проект локально

### Запуск базовой версии (`main`):
1. Склонируйте репозиторий.
2. Откройте файл `index.html` напрямую в браузере или через VS Code расширение *Live Server*.

### Запуск локального сервера разработки (после переключения на ветку `feature/modern-vite-scss`):
bash
1. Установка всех зависимостей проекта, указанных в package.json
npm install
2. Запуск локального dev-сервера (Vite)
npm run dev
